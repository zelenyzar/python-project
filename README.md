# Домашняя работа

## Содержание: 
1. Функция, маскирующая номер карты;
2. Функция, маскирующая номер счета;
3. Функция, которая фильтрует по статусу;
4. Функция, которая сортирует список по дате в порядке убывания;
5. Функция, которая принимает либо номер счета, либо номер карты;
6. Функция, которая преобразовывает в формат ДД.ММ.ГГГГ
7. Тестирование функционала
8. Фунцкия фильтрации транзакций по валюте
9. Функция вывода описания транзакции
10. Функция генерации номера карты
11. Декоратор логирования запуска и результата функции
12. Функция конвертации валюты из USD и EUR в рубли
13. Обращение к внешнему API для получения текущего курса валют и конвертации суммы операции в рубли.
