# Домашняя работа

## Содержание: 
1. Функция, маскирующая номер карты;
2. Функция, маскирующая номер счета;
3. Функция, которая фильтрует по статусу;
4. Функция, которая сортирует список по дате в порядке убывания;
5. Функция, которая принимает либо номер счета, либо номер карты;
6. Функция, которая преобразовывает в формат ДД.ММ.ГГГГ

1. Клонируйте репозиторий
(`git clone`) [GitHub] (https://github.com/zelenyzar/python-project)
2. Установите зависимости
(`pip requirements.txt`)

## Использование проекта:
1. Откройте проект;
2. Введите данные запрашиваемые программой.
